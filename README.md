# Receipt line items for Treasury (concept)
A concept mockup of a Treasury Transactions screen where a receipt photo turns one grocery charge into line items, finds the charge it belongs to, and feeds an insight and an Ask answer.
Run `npx serve` in this folder and open the local address. The sample transactions are made up. OCR runs in the browser with Tesseract.js, so there is no server and no keys.
Concept by Aarush Todimala, not affiliated with Treasury.
